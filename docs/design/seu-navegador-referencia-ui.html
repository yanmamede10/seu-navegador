Para o Claude Code: este arquivo é a referência visual das 9 interfaces (temas) que o navegador entrega na v1. Cada tema mostra a página de nova aba com a moldura do navegador (abas, barra de endereço, indicadores). Os valores numéricos (412 MB, 3 abas dormindo, 128 bloqueados etc.) e os atalhos são dados de exemplo: no app real vêm da API do navegador.

Cada tema está num <template id="tpl-<id>"> com o CSS dele, renderizado dentro de um Shadow DOM para os estilos não vazarem. O JSON #theme-tokens no fim do arquivo resume cores e fontes de cada tema. Use o markup como referência de layout e estilo; a implementação real deve separar estrutura (componentes da shell) de tema (tokens + CSS), conforme o prompt.

Y2K Maximal

y2k-maximal

Tema principal / padrão. Y2K + maximalismo, azul-marinho com rosa choque, verde-limão e ciano como apoio.

Glassmorphism

glassmorphism

Painéis de vidro fosco (backdrop-filter) sobre manchas de cor desfocadas.

Neumorphism

neumorphism

Superfície única cinza-azulada; elementos em relevo (.up) e afundados (.in).

Editorial

editorial

Layout de revista: serifa grande, fios, índice numerado, coluna lateral.

Brutalista

brutalist

HTML cru: fontes do sistema, links azuis sublinhados, bordas pretas, zero enfeite.

Neobrutalista

neobrutalist

Cores pastel fortes, bordas pretas 3px, sombras duras deslocadas.

Retrô anos 70

retro-70s

Paleta terrosa (laranja, mostarda, marrom, petróleo), listras e arco-íris de anéis.

Y2K clássico

y2k-classic

Prata com riscas, barra metálica, botões de gel aqua/verde.

Maximalista

maximal

Colagem em blocos de cor sólidos, tipografia condensada + serifa itálica.

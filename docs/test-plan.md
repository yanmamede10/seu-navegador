# QA Test Plan — Seu Navegador (SPEC §13)

Structured manual & automated regression checklist covering all critical browser invariants, memory guarantees, security boundaries, and Studio/Agent workflows.

| ID | Area | Precondition | Steps | Expected Result |
|---|---|---|---|---|
| **QA-01** | Dirty Form / `contenteditable` Protection | 2+ tabs open; Tab A has an `<input>`, `<textarea>`, or `contenteditable` editor | Type text into the field in Tab A without submitting; switch to Tab B; trigger `Sleep inactive tabs` (or wait idle timeout) | Tab A stays awake (`sleep_protected_reason = dirty-form`); typed content is preserved |
| **QA-02** | `beforeunload` Protection | Tab A registers a `beforeunload` listener | Switch to Tab B and sleep inactive tabs | Tab A stays awake (`sleep_protected_reason = beforeunload`) |
| **QA-03** | Audible Tab Protection | Tab A plays audio/video (e.g. YouTube) | Switch to Tab B; trigger `Sleep inactive tabs` or enable **Game Mode** | Tab A continues playing uninterrupted (`audible = true`) and does not sleep |
| **QA-04** | Back/Forward Stack & Scroll Across Sleep/Wake | Tab A visited Page 1 -> Page 2 and scrolled to `y = 800` | Switch away, sleep Tab A, verify disk thumbnail exists (`%LOCALAPPDATA%\SeuNavegador\thumbs`), click Tab A to wake | Tab A reloads Page 2, restores scroll near `y = 800`, and clicking **Back** navigates to Page 1 |
| **QA-05** | Session Restore with Groups | Multiple tabs organized in colored Tab Groups; `Restore session` enabled | Close Seu Navegador completely and relaunch `seu-navegador.exe` | Windows, tabs, and groups are restored; inactive tabs start in `sleeping` state (`0` wasted renderers) |
| **QA-06** | Incognito Isolation | Open Incognito window (`Ctrl+Shift+N`) | Visit external URLs in Incognito, close window, open `seu://history/` in normal window | Incognito uses `incognitoBg`/`incognitoAccent` tokens; zero visits or cookies leak to normal profile |
| **QA-07** | Hot Theme Swap (All 9 Themes) | Browser open with New Tab, Settings, DevTools (`F12`), and Studio | Switch across all 9 official themes in `seu://themes/` | Shell height, typography, tokens, New Tab, DevTools, and Studio update live with 0 JS errors and no restart |
| **QA-08** | Visual Theme Editor + Hot-Reload + `.seutheme` | Open `seu://themes/editor?base=y2k-maximal` | Change semantic color, verify live WCAG AA badges & preview, click **Save & Apply**, edit `tokens.json` on disk, export `.seutheme`, delete & re-import | Shell updates immediately on save AND on external disk edit (hot-reload); `.seutheme` roundtrips cleanly |
| **QA-09** | Imported Theme JS Security Boundary | Export `y2k-maximal` as `.seutheme` and re-import via `seu://themes/` | Activate `y2k-maximal-imported` and open `https://www.youtube.com/` | Skin CSS applies; **site JS is blocked by default** until explicit user opt-in in Gallery/Settings; `window.seu` and `window.cefQuery` remain `undefined` |
| **QA-10** | YouTube Y2K Skin & SPA Navigation | Active theme `y2k-maximal`, site skins enabled | Open `https://www.youtube.com/`, click **Player Amplo**, navigate between Home/Subscriptions/Video (SPA) | Deep navy `#070B24` skin & Shorts hiding persist across SPA transitions; toggling **"Desativar skins de sites"** in `seu://settings/` strips CSS & pill live without reload |
| **QA-11** | Ad & Tracker Blocker | Blocker enabled (default) | Visit ad/tracker-heavy site and YouTube; open Blocker popover (`shield` badge) and toggle site allowlist | Network trackers blocked, per-tab/global counters increment, YouTube scriptlets active, allowlist pauses blocking for that domain |
| **QA-12** | Themed Docked DevTools (`F12`) | Open any webpage | Press `F12`, drag splitter, switch Dock Right / Dock Bottom, hot-swap theme | DevTools docks cleanly without clipping content and inherits active `--seu-*` palette |
| **QA-13** | Game Mode (Win32 + No False Positives) | Idle tab + audible tab open; auto-detect ON | 1) Put YouTube fullscreen inside Seu Navegador for 15s; 2) Enable Game Mode manually or launch configured `.exe`; 3) Exit Game Mode | 1) Own-browser fullscreen NEVER activates Game Mode; 2) Eligible idle tabs sleep, audible stays alive; 3) Exiting Game Mode does NOT auto-wake tabs and shows MB returned |
| **QA-14** | Now Playing (`MediaSession` Shim + Fallback) | Open a tab playing media (YouTube or HTML5 `<audio>`/`<video>` with `MediaSession`) | Inspect Shell pill, Overlay media popover, and New Tab player; click Pause, Next, Prev | Metadata/title updates live; Pause/Next/Prev invoke intercepted `mediaSession` handlers (or `<video>` fallback) |
| **QA-15** | Seu Studio Split View & Browser QA | Toggle Split View (`Ctrl+Shift+E`), open project folder | Edit file in CodeMirror 6, run terminal command, click **Inspecionar** in QA panel on paired browser tab | Studio opens in `< 150 ms`, inherits active theme, and inspects DOM/console of the paired real tab |
| **QA-16** | Shortcuts & Focus Stability | Open multiple tabs, Studio, and external site | Press `Ctrl+T`, `Ctrl+L`, `Ctrl+W`, `Ctrl+Tab`, `Alt+Left/Right`, `F5` repeatedly | Keyboard focus remains inside the active view/omnibox; `Alt` shortcuts never trigger Win32 system menu focus steal |
